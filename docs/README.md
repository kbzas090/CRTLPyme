# Documentación del Proyecto CRTLPyme

Este directorio contiene toda la documentación técnica generada durante el desarrollo, mantenimiento y resolución de problemas del proyecto CRTLPyme.

## 📁 Estructura de Documentación

### 🚀 deployment/
Documentación relacionada con el despliegue en Google Cloud Platform (GCP) y Cloud Run:
- Configuraciones de servicios
- Reportes de revisión de GCP
- Instrucciones de despliegue
- Resúmenes de limpieza de servicios

### 🔧 fixes/
Documentación de correcciones y soluciones implementadas:
- Correcciones de autenticación (NextAuth)
- Fixes de landing page y planes de suscripción
- Soluciones de logout y redirección
- Recuperación de componentes perdidos
- Guías rápidas de solución de problemas

### 📊 analysis/
Análisis técnicos del código y la arquitectura:
- Análisis de planes de suscripción
- Análisis de seed/poblado de datos
- Cambios en planes y límites
- Estado actual del sistema
- Análisis de código y versiones de GitHub

### 📈 reports/
Reportes completos del estado del proyecto:
- Reportes de funcionalidades SaaS
- Investigación de base de datos
- Reportes de módulos
- Tareas completadas
- Reportes de URLs de servicios

### 📚 guides/
Guías y procedimientos operativos:
- Guía de inicio rápido (Quick Start)
- Resúmenes de seeding
- Planes de poblado de datos paso a paso
- Propuestas de poblado de datos
- Acciones rápidas para seed

## 📝 Nota sobre Formatos
